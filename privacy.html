プライバシーポリシー

「Outlook 予定同期（個人）」（以下「本アプリ」）は、作成者本人だけが自分のデータに対して使う個人用ツールです。

1. 取得する情報

  • 本人の Outlook の予定の件名・開始日時・終了日時・終日かどうか
  • 重複を避けるための、本人の Google カレンダー（メインのカレンダー）の予定（件名と日時）の読み取り

出席者・本文・場所・会議の URL は取得・送信しません。

2. 利用目的

本人の予定を、本人の Google アカウントのメインのカレンダーへ写すことだけに使います。本アプリが変更・削除するのは本アプリが書いた予定（印の付いた予定）だけで、本人が自分で入れた予定は変更・削除しません。

3. 第三者への提供

取得した情報を第三者へ提供・販売・共有しません。広告や分析には使いません。

4. 保存

Google の認証情報は、本人が管理する端末の、利用者ごとに分離した保管庫に保存します。予定のデータは、同期の処理と、本人の端末上の作業記録以外には保存しません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

6. 削除

本人は、Google アカウントの「サードパーティのアクセス」から本アプリの許可をいつでも取り消せます。本アプリが書き込んだ予定は説明欄に「Outlook 同期」とあり、本人が Google カレンダーの画面からいつでも削除できます。

7. 問い合わせ

Google の同意画面に表示されるサポートメールアドレスへご連絡ください。
